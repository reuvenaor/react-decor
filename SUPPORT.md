# Support

- **Questions / "how do I…"** — open a [GitHub Discussion](https://github.com/reuvenaor/react-decor/discussions)
  (or an issue with the question label if Discussions is not enabled yet).
- **Bugs** — open an issue with the **Bug report** template. A minimal `*.at.tsx`
  snippet plus the AT-coded diagnostic (if any) makes fixes fast.
- **Feature ideas** — the **Feature request** template.
- **Security issues** — never a public issue; see [SECURITY.md](SECURITY.md).
- **Reference docs** — [lib/react-decor/README.md](lib/react-decor/README.md) and the
  docs site (`npm run dev`).
